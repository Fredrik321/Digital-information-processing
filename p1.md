### Format, array shape, data type, units, range, and byte size
All images are in `.jpg` format.

The images are classified into six different bird-species categories:

- American Goldfinch: 143
- Barn Owl: 129
- Carmine Bee-eater: 131
- Downy Woodpecker: 137
- Emperor Penguin: 139
- Flamingo: 132

This gives a total of 811 images.

All images have the shape `(224, 224, 3)`. The data type is `uint8`, and the values represent pixel intensity in the range 0-255. The uncompressed in-memory size can be calculated as follows:

`811 * 224 * 224 * 3 = 122,078,208 bytes`

The values have no physical unit. They are 8-bit sRGB code values (gamma-encoded), not linear light intensities, and the full range 0-255 is used in the dataset. On disk, the 811 JPEG files take up 15,967,831 bytes in total (about 15.2 MiB). This means the dataset is already lossy-compressed about 7.6 times compared to the uncompressed array.

### Sampling rate and spacing
The images are sampled on a regular grid with a spacing of 1 pixel in the horizontal and vertical image coordinates. The physical spacing in the photographed scene, camera distance, lens, and capture sampling rate are unknown because they are not included in the dataset metadata. All images have a resolution of 224 x 224 pixels and are stored using three colour channels. The distance from and angle to the camera are not controlled or documented, and they vary between images. Most pictures appear to be taken from a side angle. Although the images appear to be genuine photographs of birds, some are drawings. Therefore, spatial frequencies are reported in cycles per pixel rather than cycles per metre.
### Transformation experiment
For this experiment, the transformation used is Sobel edge detection.

**Prediction:** The Sobel edge detection will produce stronger and more
accurate responses at high-contrast features such as the beak and eye,
and weaker responses across the body where brightness changes are more
gradual. The strength of the bird's outline will also depend on the
contrast between the bird and its background. For example, a penguin's
white stomach will produce a weaker outline against a snowy background.

The result matched this prediction. The beak, eye, feather boundaries, and bird outline produced stronger Sobel responses than smooth body regions. The outline was weaker where the bird and background had similar brightness.

### Quantisation/resampling experiment
As detailed in the notebook, quantisation is performed by reducing the bit depth from 8 bits to 1 bit for an image from the dataset. The experiment includes both a prediction and observations about how this affects the images. This uses one selected image, so the result is illustrative rather than a claim about every image in the dataset. At low bit depths, banding and false colour regions appear, while the broad bird shape remains more recognisable than fine texture.

### Frequency-domain finding
The 2-D spectral power distribution shows that most power is concentrated at low spatial frequencies. These frequencies represent large-scale shapes, smooth backgrounds, and the overall bird structure. Higher frequencies represent edges, feather texture, and other fine detail. No single high-frequency component is shared by all species, so the spectrum describes image structure rather than providing a complete species identifier.

The frequency view in the notebook is calculated from the mean image of the dataset. Averaging 811 differently framed images blurs them, which works like a low-pass filter, so this view exaggerates how much power sits at low frequencies compared with a single image. It shows the shared structure of the dataset, not the detail in any one photo.

To test whether the spectrum carries species information at all, we used the radially averaged power spectrum of each image as a feature vector for a random forest classifier (75/25 stratified split, fixed seed). It reached 46.8% test accuracy against a six-class chance level of 16.7%. The spectrum therefore holds some species information, and the Downy Woodpecker was recognised best (recall 0.79), possibly because of its high-contrast black-and-white plumage. However, it is far from enough to identify the bird on its own. The American Goldfinch was recognised worst (recall 0.19).

### Reproducible loader
The notebook contains a loader consisting of two functions for loading and viewing the dataset, plus a third function for creating the baseline representation for P2. The loader improves reproducibility by sorting the image paths deterministically and assigning the images a fixed data type. The P2 baseline is the complete dataset represented as one array with shape `(811, 224, 224, 3)`, dtype `uint8`, values in the range 0-255, and an uncompressed size of 122,078,208 bytes. Before calling `np.stack`, the loader checks that every converted image has shape `(224, 224, 3)` and raises an error otherwise, so a changed or corrupted file cannot silently alter the baseline.

### Visual Informatics concern
One concern for this dataset is the variation in the birds backgrounds. Inspection shows that the images were taken in different environments. For instance this could cause problems if the data where to be used in machine learning, because a model might classify images based on visual elements such as foliage, branches, or snow rather than on the birds themselves.

### Integrity concern
The dataset lacks information about the images themselves. Although all images are labelled according to bird species, metadata such as the original capture conditions and preprocessing history is not provided. This is an integrity concern because it limits our ability to verify how the images were originally captured or processed. For example, although the images currently have the same dimensions, we cannot determine whether they originally had the same resolution or whether they were resized or otherwise processed before being included in the dataset. This also makes it difficult to determine what effect preprocessing may have had on the images.
